git init - создает новый репозиторий в текущей папке
git clone - скачивает чужой репозиторий с GitHub на компьютер
git status - показывает, какие файлы изменились, а какие еще нет
git add - добавляет файлы в список для следующего сохранения
git commit - сохраняет изменения в истории (делает снимок)
git push - отправляет сохраненные изменения на GitHub
git pull - скачивает изменения с GitHub и сразу применяет их
git log - показывает список всех сделанных коммитов
git branch - показывает список веток или создает новую
git checkout - переключает на другую ветку или возвращает файлы
